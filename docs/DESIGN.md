# DESIGN.md

Este documento define criterios generales de diseño de producto e interfaz.

## Principios de diseño

- Priorizar claridad sobre complejidad visual.
- Diseñar interfaces simples y entendibles.
- Reducir pasos innecesarios.
- Usar lenguaje claro para el usuario.
- Mantener consistencia visual.
- Considerar estados de carga, error, vacío y éxito.
- Diseñar para accesibilidad básica desde el inicio.

## Reglas generales

- Cada pantalla debe tener un propósito claro.
- Cada flujo debe tener una acción principal identificable.
- Los mensajes de error deben indicar qué ocurrió y cómo corregirlo.
- No agregar elementos visuales que no aporten al objetivo del usuario.
- Evitar interfaces sobrecargadas.
- Mantener jerarquía visual clara entre títulos, acciones y contenido.

## Estados mínimos de interfaz

Toda funcionalidad relevante debe considerar:

- Estado inicial.
- Estado de carga.
- Estado exitoso.
- Estado vacío.
- Estado de error.

## Accesibilidad mínima

Antes de cerrar una pantalla o flujo, revisar:

- El texto es legible.
- Los controles importantes tienen etiquetas comprensibles.
- Los colores no son la única forma de comunicar estado.
- Los mensajes de error están cerca del elemento afectado cuando sea posible.
- El contenido no se superpone en pantallas pequeñas.

## Checklist de diseño

- ¿La pantalla comunica qué puede hacer el usuario?
- ¿La acción principal es evidente?
- ¿Los estados de carga, vacío y error están definidos?
- ¿El lenguaje es claro y directo?
- ¿La interfaz evita elementos decorativos innecesarios?
- ¿La experiencia se mantiene comprensible en móvil y escritorio?

## Criterio de buena interfaz

Una interfaz es adecuada cuando el usuario puede entender qué hacer sin necesitar una explicación extensa.
