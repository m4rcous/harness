## Criterios de aceptación generales

El producto se considera aceptable cuando:

- Resuelve el problema definido en este documento.
- Cumple los requisitos funcionales priorizados.
- Respeta las restricciones técnicas o académicas declaradas.
- Maneja errores y estados vacíos relevantes.
- Cuenta con evidencia mínima de validación, pruebas o revisión.
