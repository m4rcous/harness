# Design Docs Index

Este índice lista los documentos de diseño disponibles en el proyecto.

## Documentos principales

- `core-beliefs.md`: principios base del Harness y del diseño de proyectos.

## Cuándo crear un design doc

Crear un documento de diseño cuando:

- Se toma una decisión técnica importante.
- Se diseña un módulo complejo.
- Se define un flujo relevante del sistema.
- Se modifica la arquitectura.
- Se requiere justificar una solución para revisión académica o técnica.

## Formato sugerido

Cada design doc debería incluir:

1. Contexto.
2. Problema.
3. Alternativas evaluadas.
4. Decisión tomada.
5. Consecuencias.
6. Riesgos.
7. Relación con otros documentos.
